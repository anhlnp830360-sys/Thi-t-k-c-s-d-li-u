\section{REQUIREMENT TRACEABILITY MATRIX (RTM)}\label{s:rtm}

The Requirement Traceability Matrix (RTM) establishes the relationship between functional requirements, corresponding use cases, system modules, and test cases. It ensures that each functional requirement can be traced to an implemented system function and verified through testing.
